# YİÜSEM WhatsApp Otomasyon Sistemi 🎓

Bu proje, **Yüksek İhtisas Üniversitesi Sürekli Eğitim Merkezi (YİÜSEM)** için geliştirilmiş, TypeScript tabanlı bir WhatsApp asistan botudur. Müşteri iletişimini hızlandırmak, mesai saatleri dışındaki talepleri yönetmek ve kurumsal bilgilendirmeyi otomatize etmek amacıyla tasarlanmıştır.
